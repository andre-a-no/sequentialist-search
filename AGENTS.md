# Repository context

This repository is currently planning-only. Read [README.md](README.md) and the
[overview](docs/overview.md) before making changes. No package, runtime, public
API, installation workflow or general solver is implemented here.

`sequential-*` contains mathematics/cybernetics and pure algorithmic abstractions.
`sequentialist-*` contains reusable engineering and application software. This
repository is reserved for a possible search-engineering layer; its exact scope
remains a design decision. Preserve the boundary with `sequential-search`,
`sequentialist-agentic` and `sequentialist-core`.

For documentation/planning work, keep proposed capabilities explicitly labeled
as planned. Do not invent APIs, versions, install commands or implementation
claims. An explicit implementation task may later change the repository status;
update the status and acceptance evidence together when that happens.

Use English for technical guidance. Public noncoding overviews are maintained
in English and Russian by user request; keep their status and claims aligned.
Keep local links valid and maintain
the curated [llms.txt](llms.txt) index when adding public documentation. Discovery
files describe content; they do not guarantee search indexing or answer rankings.
